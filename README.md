# E-Archive
A web-based archive management system developed during my internship at the East Java Province Public Works Department.

## 📌 Overview

E-Archive is designed to simplify archive management by allowing users to organize, search, and manage digital documents efficiently through a responsive web interface.

## ✨ Features

- User Login
- Dashboard
- Archive Management
- Search Archive
- Responsive Design

## 🛠️ Tech Stack

- HTML
- CSS
- Bootstrap
- JavaScript

## 👩‍💻 My Role

Front-End Developer

Responsibilities:

- Developed responsive user interfaces
- Designed website layouts
- Integrated frontend with backend
- Improved website responsiveness
